# The Great Prettification — Pounder

A refreshed look for Pounder in FiveM. This is a replacement vehicle pack.

## Installation

1. Download the repository ZIP or the attached resource ZIP when available.
2. Copy the FiveM resource folder into your server's `resources` directory.
3. Add an `ensure <resource-folder-name>` line to `server.cfg`.
4. Restart the resource or server and spawn the vehicle.

**Replacement vehicle:** `pounder`. Avoid running another resource that replaces the same vehicle.

See the repository README for the full livery list and vehicle-specific instructions.
